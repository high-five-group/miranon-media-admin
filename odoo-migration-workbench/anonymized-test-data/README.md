# Anonymized Test Data

Inga anonymiserade testdatafiler skapades i denna körning eftersom faktisk Airtable-export/API saknas.

När export finns ska anonymisering:

- ersätta namn med fake-namn,
- ersätta e-post med `example.com`,
- maskera telefon,
- bevara relationer via test-ID:n,
- ta bort känsliga anteckningar om de inte behövs för mapping,
- dokumentera transformen.
