# Generated Import Package

Status: koncept/blockerat.

Inga skarpa importfiler skapades eftersom:

1. Faktiska Airtable-exporter saknas.
2. Faktiska Odoo-importfält saknas.
3. Odoo-instansen och testdatabasen är inte verifierade.

Första skarpa paket ska skapas först efter field inventory och import preview.
