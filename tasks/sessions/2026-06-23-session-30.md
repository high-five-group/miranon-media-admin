## Del 1 — Syfte och scope

### Syfte

Bygga **Fas 6d — Hem-aggregering**: `/hem`-vyn med greeting + nya anmälningar +
info-cards + CTA, aggregerad ur de read-EF:er som 6a+6b+6c redan deployat. Ingen
ny Edge Function väntad (byggplan §4 6d-raden, rad 625). Polling-mekaniken
implementeras per [ADR-017](../../docs/decisions/ADR-017-polling-vs-realtime.md)
(Accepted): hybrid polling 60s + pull-to-refresh + visibility-trigger; Realtime
defer:as till Fas E.

### Ordnad scope (preliminär landnings-struktur — förfinas mot disk vid L1-design)

- **L1** — `/hem`-route + greeting + aggregerings-cards mot **befintliga read-EF**
  (`fetchEvents` / `fetchRegistrations` / ev. `fetchWaitlist` via router-context-DI,
  ADR-055). Mönster-arv från 6a/6b/6c: `useDataSource()` + `useQuery({ queryKey:
  queryKeys.<domän>, queryFn })`. Kvalitetsribba 11/10/10, axe 0. Ny
  `queryKeys.dashboard`-gren i `src/queries/keys.ts` (factorn förutser den redan,
  kommentar rad 7).
- **L2** — polling-mekanik per ADR-017 (`refetchInterval: 60_000` +
  `refetchIntervalInBackground: false` + pull-to-refresh + visibility-trigger) +
  Playwright-baseline.

> **Landnings-strukturen är preliminär** — den slutliga L1/L2-skärningen sätts av
> Chat i L1-bygg-prompten efter denna orienterings-rapport. Del 2+ föds vid
> respektive landning.

### Inte i scope

- Fas 6e (Mer) — fristående, egen fas.
- Nya Edge Functions — 6d konsumerar enbart befintliga read-EF (verifierat:
  `fetchEvents` / `fetchRegistrations` / `fetchWaitlist` finns i `DataSourceAdapter`,
  motsvarande `get-events` / `get-registrations` / `get-waitlist` deployade).
- Supabase Realtime (Fas E, ADR-017 §5 — ny ADR superseder ADR-017 vid Fas E).
- **Inget nytt ADR väntat.** Dyker något arkitektoniskt upp → STOPPA (ADR-053-triage).

**Greeting namn-källa:** STATISK "Hej! Här är din översikt." — `AuthUser` (`src/auth/AuthProvider.tsx`)
bär bara `id` + `email`, **inget namnfält** (verifierat, ej antaget). E-post i hälsning vore varken
varmt eller Gunilla-begripligt → neutral hälsning tills namnfält finns.

**Obetald-indikator fält-form verifierad:** `Anmälningsavgift` är **singleSelect** (Mottagen /
Ej mottagen) per `docs/reference/data-model.md:193` — INTE formel/rollup → trygg läs/jämför.
"Ej relevant (för föreläsningar)" räknas EJ som obetald. Ingen status-blandning (Avbokad/Inställt
filtreras inte bort i L1 — medvetet, samma temporal/status-renhet som övriga cards).

**T14-beröring:** NastaEvent avgör "kommande" temporalt (`startdatum` vs idag), exakt som 6b:s

### Arkitektur-mönster

- **queryKeys.dashboard-gren:** `{ all: ['dashboard'], registrations: ['dashboard','registrations'],
  events: ['dashboard','events'] }`. EGNA nycklar (ej återbruk av events.list/registrations.byEvent)
  så L2:s 60s-polling kan scopas exakt till dashboard utan att tvinga /event-listans cache att polla.
- **Loader vs ren-useQuery:** **ren useQuery i komponenten** — speglar disk-precedenten (grep:
  noll `loader`/`ensureQueryData` i `src/routes/`; alla 6a/6b/6c-vyer self-fetchar i komponenten).
  STATE-STRATEGY §5b:s loader-skiss följdes INTE (divergens mot disk-precedent, medvetet).
- **a11y:** ingen h1-autofokus (landningsyta → skip-link-först; RouteAnnouncer + staticData.title bär
  navigations-a11y, speglar EventsList). Cards = `<section aria-labelledby>` (region-landmarks),
  h1→h2-hierarki, pending=`role=status`, fel=`role=alert` (MessageBox). axe 0.

### Test 5-flytt (beslut A) + klass-korsläsning

ADR-017-orelaterat: 6d gör inloggat `/hem` datafetchande, vilket bröt tre **pre-existing** tester
som pinnade /hem som inert. Klass-korsläsning (grep alla `/hem`-träffar i `tests/e2e/`) gav:

- **auth-flow Test 5** (`INGA functions/v1/*-anrop`, "arkitektur-kritiskt") — **omskriven (väg A)**:
  flyttad från inloggat /hem till den **oinloggade vägen** (navigera /hem utan session → assertera
  noll EF-anrop FÖRE /login-redirect). Invarianten (anon-key-fallback-förbud, sessionsdok Del 5.0)
  står ORÖRD; bara regressions-pinnen flyttad till sin sanna kontext (guard-före-datafetch =
  oinloggat). Test-kommentaren förklarar varför pinnen flyttade.
- **shell DoD 1** (`header`=1) — min `Hem.tsx` använde `<header>` på greeting → ändrat till `<div>`.
- **shell DoD 2** (skip-länk-fokus) — min h1-autofokus stal fokus → borttagen.
- Övriga /hem-träffar (auth.setup, auth-flow Test 3/4/6, shell DoD 3/1+9/10) = URL/h1-text/skal-chrome,
  **opåverkade**. Inga andra invarianter berörda → ingen ytterligare STOPPA.
