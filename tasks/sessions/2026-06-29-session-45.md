## Del 1 — Syfte och scope

### Syfte

Session 45 bygger T50 — UI-härdningen som gör ett oavsiktligt massutskick fysiskt
omöjligt för en icke-teknisk användare (Lotta). Det TREDJE oberoende skyddslagret
(UI-bekräftelsen) mellan ett oavsiktligt klick och en riktig inkorg, utöver (a)
idempotensnyckeln och (b) fail-closed-spärren. Måste vara på plats innan spärren
öppnas (Grind F) och Lotta sänder skarpt.

### Scope (golvet — härda befintliga SegmentMailCompose; ingen ny server/EF/ADR)

- **Granska-steg:** ruta i bekräftelse-modalen som återger exakt vad som händer —
  mottagar-ANTAL (emfaserat, fokalt), segmentnamn, ämne, och förhandsvisning av
  mailtexten.
- **Skriv-för-att-bekräfta:** Skicka-knappen låst (aria-disabled via React Aria
  `isDisabled`, EJ native `disabled`) tills användaren skriver mottagar-antalet;
  exakt sträng visas vid fältet; upplåsning vid exakt match aviseras i
  aria-live-region.
- **Faro-intent** (`intent="danger"`) på den oåterkalleliga slutknappen — fixar
  forensik-AVVIKELSE (i dag `intent="primary"`); outcome-label "Skicka till N
  personer", aldrig "OK".
- **Avbryt** som tryggt förval, spatialt separerad från faro-knappen.
- **Bevarade golv:** pessimistisk UI, stabil idempotens, server-side
  consent/resolve (segmentIds-only, aldrig klient-lista), partial aldrig binär,
  auto-trigger-invarianten (send endast från explicit `onPress` — ingen
  `useEffect`/auto-väg), a11y axe 0.
- **Test:** UTÖKA befintlig Playwright-baseline
  (`tests/e2e/mer-segment-send.staging.test.ts`) med MOCKAT send — aldrig live
  (säkerhets-invarianten: Code initierar aldrig skarpt utskick).
