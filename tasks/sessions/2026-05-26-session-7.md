### K0.1 — Fynd 1: typecheck no-op → ärlig ✅ KLAR (2026-05-27)

Commit: `3c8c3f6` (package.json + ci.yml). Källa: Fynd 1 (11/10-blocker) i
[`docs/analysis/Fas-2-11-10-verification-2026-05-14.md`](../../docs/analysis/Fas-2-11-10-verification-2026-05-14.md),
verifieringsdokets rekommenderade stängnings-ordning steg 1.

`tsc --noEmit` utan `-b` ignorerar TypeScript project references
(`tsconfig.json` = `files: []` + references → app/node/tests) → den namngivna
typecheck-signalen var no-op för app-koden (build fångade typfel via `tsc -b`,
men signalen self var falsk-grön).

- package.json:10 `typecheck` → `tsr generate && tsc -b --noEmit`.
- ci.yml:110 `TypeScript check` → `npm run typecheck` (CI + lokalt delar samma
  kommando — single source of truth).
- TS 6.0.3 (≥ 5.6) → `tsc -b --noEmit` stöds; flagg-kombo torrkört (bygger alla
  3 refererade projekt).
- **Negativ test (empiriskt bevis):** TS2322 injicerat i `src/lib/cn.ts`
  (app-scope) → ny form `npm run typecheck` exit **2** (fångar), gammal
  `npx tsc --noEmit` exit **0** (fångar inte). No-op + fix bägge bevisade.
  Probe reverterad byte-identisk (`9ad0df4`).
- Ren körning: `npm run typecheck` exit 0, 0 fel (inga pre-existerande typfel).
- **Öppen tråd (transparens):** spoke `.claude/settings.json` pre-commit-hook
  kör fortfarande `npx tsc --noEmit` (samma no-op-form — tredje platsen).
  Utanför Fynd 1:s dokumenterade scope (verifieringsdok rad 180-181 =
  package.json + ci.yml) och en K0.0-skyddad governing fil → lämnad orörd;
  Chat/Marcus-beslut.

### K0.1c — Fynd 1 äkta klass-stängning + grind-arkitektur ✅ KLAR (2026-05-27)

Commits: `9630c31` (arkitektur — ADR-036 + ADR-001/010-korrigering + settings.json
dead-config-borttagning); `0401108` (7 docs-rättningar); denna commit (trail + lesson).
K0.1:s "öppna tråd" löstes genom att hela buggklassen stängdes, inte bara platsen.

- **Uttömmande repo-grep** (no-op-typkoll-mönster): **noll exekverande no-op kvar**
  efter K0.1. `typecheck:tests` (`tsc -p tsconfig.tests.json`) verifierad legitim
  (löv-projekt med egna includes). Den enda återstående exekverbara platsen —
  `.claude/settings.json` pre-commit-hook — visade sig **icke-exekverande**.
- **Empiriskt fynd (K0.1b):** pre-commit-kvalitetsgrinden har **aldrig existerat**.
  `hooks.pre-commit` i settings.json är dead config (Claude Code har inget
  `pre-commit`-event); `.githooks/pre-commit` gör bara frontmatter-bump. En fil med
  `debugger;` committades rent — Biome kördes aldrig. ADR-001 + ADR-010 bar ett
  overifierat enforcement-claim sedan Fas 0.
- **Beslut C (Marcus/Chat):** CI är **enda** mekaniska enforcement-grinden (Biome +
  `npm run typecheck`, äkta efter K0.1). Ingen mekanisk lokal grind; lokal kvalitet
  = DoD-disciplin. Alt A (äkta pre-commit) + pre-push avvisade (anti-mönster /
  kringgåbara). → [ADR-036](../../docs/decisions/ADR-036-kvalitetsgrind-ci-enda-mekaniska-enforcement.md).
- **Utfört:** ADR-036 skapad; ADR-001 + ADR-010 fick additiva korrigerings-noter
  (immutabilitet — beslutstext orörd); döda `hooks`-blocket borttaget ur settings.json
  (kirurgisk Edit, K0.0-protokoll, spoke-fil byte-diff = endast hooks); 7 docs-rättningar
  (`npx tsc --noEmit` → `npm run typecheck` i CLAUDE.md / CONTRIBUTING / PR-template /
  byggplan / byggplan-direktiv; README + SECURITY grind-beskrivningar mot CI-verkligheten).
- **Ny ärlig DoD-modell:** `npm run typecheck` + Biome kördes manuellt grönt före varje
  commit (ingen mekanisk grind finns). `.githooks/pre-commit` bekräftades fyra
  (frontmatter-bump) medan settings.json-hooken aldrig gjorde det.

Fynd 1 nu **äkta klass-stängt**.
