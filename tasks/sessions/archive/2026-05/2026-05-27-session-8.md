ADR-039; sessionsdok + lessons + todo; undersök sessions-numreringskonventionen (DEL 5).

CC-tooling); generell konsistens-audit-skill (K0a visade ej systemiskt → undvik
överengineering); fel-hanterings-arkitektur-konsolidering (ADR-038:s öppna frågor);

## Del 5 — Sessions-numreringskonventionen ✅ RESOLVED → [ADR-040](../../docs/decisions/ADR-040-sessions-numreringskonvention.md)

> **K0b-resolution (2026-05-27):** Marcus valde plats (ny ADR-040) och innehåll (sekventiella heltal, inga decimaler; en session = en logisk arbetsenhet; faser separat axel; historiska decimal-sessioner grandfathrade). Originalförslaget bevarat nedan som historisk trail.

**Vad jag sökte:** en faktisk definition av hur sessioner NUMRERAS (heltal vs decimal; vem
tilldelar; var registreras).

**Vad jag fann:**

- [ADR-023](../../docs/decisions/ADR-023-sessions-arkivering.md) § "Konvention för framtida sessions"
  täcker sessionsdok-**filnamn** (`<datum>-<tema>.md`) + arkivering + split-tröskel — **inte**
  nummer-tilldelning.
- [byggplan.md:16](../../docs/byggplan.md) definierar **ADR**-numrering ("tilldelas av Code mot
  befintlig katalog vid commit-tillfället") — inte session-numrering.
- Ingen definition i spoke- eller hub-CLAUDE.md, byggplan, eller skills.
- **Empiriskt mönster** (otydligt formaliserat): 6 → 6.5 → 6.6 → 6.6.5 → 6.6.6 → 6.6.7 → 6.7 → 7 → 8.
  Decimaler används för inskjutna sub-/mini-sessioner mellan heltal; finare decimal = djupare insticks-nivå.

**Slutsats:** ingen formell definition existerar — samma klass som ADR-023-vs-skill-tvetydigheten
K0a loggade (styrande konvention oklart definierad).

**Förslag (ej committat — kräver Marcus):**
- **Plats:** kort sektion i spoke-CLAUDE.md `## Operativ procedur`, ELLER ny ADR-040 (nästa lediga).
- **Innehåll (utkast):** heltal = primär arbets-/fas-session; decimal = inskjuten process-/
  underhålls-session mellan heltal (varje decimalnivå = finare insticks); numret deklareras av
  Marcus + Chat vid sessionsstart och registreras i sessionsdok-titel + todo "Aktuellt fokus".

🛑 **STOPPA:** att fastställa en styrande konvention är ett beslut som kräver Marcus. Verifierat,
föreslaget — committas inte förrän Marcus valt plats + innehåll. (Separat från K0b:s atomiska commit.)
