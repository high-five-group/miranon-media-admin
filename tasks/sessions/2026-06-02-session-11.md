### Drift-fix + CI-integritetsfynd under landning

Inkrement 1:s grön-bekräftelse blockerades av fem PRE-EXISTING externa länkfel i ORÖRDA filer (ej inkrement-1-orsakade — verifierat: commits rörde aldrig de felande filerna, deltan har noll markdown-länkar). Hanterat som separat, snävt scopad sub-uppgift, ej inbakat i inkrement 1.

**Två fel-klasser:**
- **UA-WAF (406/415):** airtable.com ×3 [406] + travisgosselin.com [415]. Anslutningen kom fram; servern avvisade lychee:s default-User-Agent. Root-fix: browser-`User-Agent` via lychee `--header` (commit `6274918`) — checkar länken på riktigt (404 fångas fortfarande), tystar inget. CI-validerat: alla fyra → 200/OK. Chats ursprungliga `--accept`-väg revs öppet (premissen "406/415 nät-oberoende, lokalt bevisbart" falsifierad av Code:s lokala test: URL:erna gav 200 lokalt; felet är miljö-/UA-drivet).
- **Connection-block (timeout):** digg.se/webbriktlinjer [TIMEOUT], persistent på två färska tom-cache-fetch, lokalt nåbar. Samma klass som befintliga tanstack/opentelemetry-undantag (GHA-IP strypt). → `.lycheeignore` smalt mönster (commit `6274918`), 2-instans-beslut med re-utvärderings-flagga.

**Tre CI-integritetshål (samma felklass: kollen rapporterar OK/skippat utan att spegla verklig länk-status):**
1. **Cache-maskering:** lychee-cachen (`cache-lychee-${github.sha}` + restore-keys-prefix + `--max-cache-age 1d`) serverade de tre airtable [406] som OK — main var grön-av-cache, inte grön-av-verklighet, tills Code bustade cachen och tvingade fram en äkta fetch. ÖPPET (ADR-044-kandidat).
2. **Skip-utan-revalidering:** en commit som rör endast `ci.yml` + `.lycheeignore` triggade inte docs-jobbets changed-files-grind → Docs link check hoppades över → `--header`-fixen committades men kördes aldrig (ihåligt grönt). LAGAT (B-fix nedan).
3. **Config-utan-revalidering** (samma rot som #2): en ändring av själva länk-konfigurationen re-validerade inte kollen. LAGAT via decoupling (commit `6a0ab9c`): separat `changed-docs`-härledningssteg (väg ii-a) som inkluderar `.lycheeignore` + `ci.yml` i `docs_changed`, medan `should_skip_tests`/`!.github/workflows/**`-valet lämnades bevisbart orört (Test+Build körde på ci.yml-only-commiten — decoupling-regression passerad).

**Commit-trail (Session 11):** `9ba7a58` (sessionsdok-födelse) → `16a4e9f` (hub-bas) → `393ec9c` (spoke-delta + ADR-043→Accepted + README) → `6274918` (browser-UA + digg.se-ignore) → `6a0ab9c` (decouplad docs_changed, self-trigger som CI-validerade allt).

## Del 8 — Lessons (kandidater, skördas vid stängning)

Kandidater (formell skörd + L-numrering vid stängning):

- **K-a:** Hårdkodad förväntad-HEAD i en prompt blir inaktuell när mellanliggande commits landar inom samma session → ankra mot "senast rapporterade commit", ej hårdkodad SHA. (Instans: 1B HEAD-ankar-STOPPA.)
- **K-b:** Ett verifierings-filter snävare än felrymden maskerar fel (grep på [404]/[400]/[500] missade [415]). Assertera mot hela felmängden. (Instans: attempt-1-rapportens missade [415].)
- **K-c:** `--cache` + restore-keys-prefix + max-cache-age döljer extern länk-röta; "grön" kan vara grön-av-cache, inte grön-av-verklighet. (Instans: airtable [406] cache-maskerade.)
- **K-d:** Att sluta sig till en statuskods ORSAK ur dess BETYDELSE är en gissning förklädd som slutsats — 406/415 "betyder" content-negotiation men ORSAKEN här var UA-WAF + miljö. Verifiera orsaken empiriskt. (Instans: Chats falsifierade `--accept`-premiss.)
- **K-e:** Ett hoppat eller cachat CI-jobb kan rapportera success utan att validera något — assertera EXPLICIT att den validerande körningen faktiskt kördes (per-jobb success ≠ skipped). (Instans: ihåligt grönt, docs-jobb skippat.)
- **K-f (Code-sido):** Pipe-exit-kod ≠ auktoritativt resultat; använd `gh run view --json conclusion`. (Instans: attempt-2 "watch-exit 0" var tail:s exit.)

Meta-tråd: K-b/c/d/e klustrar som "verifiering snävare/inaktuellare/grundare/maskerad än verkligheten" — stark [UNIVERSAL] hub-lyft-kandidat.
