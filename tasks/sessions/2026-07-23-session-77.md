## Del 1 — Syfte och scope

### Syfte

Svara upp processgranskningens fynd med mekanik i stället för
överenskommelser: mekanisera merge-grinden (ruleset på main —
ADR-029:s utelämning #5 stängs), stänga actionlint-supply-chain-
luckan (utelämning #3 migreras till husets shellcheck-mönster),
splitta Test+Build så staging-mutexen bara bärs av staging-stegen,
landa den riskanpassade CI-designen (våg 2) som research-dok, och
ta upp helheten i tråd-substratet (T85). Beslut låsta 2026-07-23:
**A** — all bokföring via auto-merge-PR efter grind-aktivering
(ingen bypass); **A** — rött-först-bärarbytet (verkställs som
ADR-071-amendering i våg 2c, EJ denna session; L317 är nytt
empiriskt stöd).

### Scope (ordnad körordning)

0. **Svars-sektionen** (Codes verifikation + beslutsläge) appendas
   i processgranskningens research-dok + **BUILD-LOG-erratum**
   (S75-postens numrerings-rad "nästa: 076" → 077, fel mot disk).
   Sista direktpush-era-landningarna.
1. **Ruleset "main-skydd"** via API: PR-krav (0 approvals — löser
   solo-paradoxen) + required check "CI Passed or Skipped" med
   strict up-to-date + force-push-/deletion-block; TOM bypass-lista
   (nödvägen är synlig ruleset-inaktivering, aldrig tyst gräddfil).
   Repo-inställningen `allow_auto_merge` aktiveras. Grind-bevis:
   direktpush avvisas · force-push avvisas · grön PR auto-mergar ·
   merge BLOCKED under pågående CI (inget avsiktligt rött —
   L317-koherent bevisform).
2. **actionlint → shellcheck-mönstret** (release-pinnad version +
   egen SHA256-verifiering) i ci.yml.
3. **Test+Build-splitten**: `test-fast` (pure+build) + `a11y` +
   `test-staging` (ENSAM mutex-bärare, jobb-nivå-dependabot-skip →
   ADR-073-amendering 2:s villkorliga grupp retireras);
   fetch-depth-bärar-invarianten (ADR-039/054) + dess test-svit
   uppdateras ärligt i samma commit. Steg 2+3 i EN PR — som
   samtidigt blir första skarpa beviset på nya grinden.
4. **Dokumentation + upptag**: ADR-076 "Merge-grinden" (ruleset-
   JSON kanonisk + A/B-beslutet + bevisen) · ADR-029-noter
   (utelämning #3 migrerad, #5 stängd) · CONTRIBUTING § Pull
   Request-flöde (mekanisk grind ersätter överenskommelse-
   formuleringen) · decisions/README-katalograd + räkning 75→76 ·
   våg 2-designen landas som
   `docs/research/riskanpassad-ci-design-2026-07-23.md` · tråd
   **T85** registreras · todo-/BUILD-LOG-kadens.
