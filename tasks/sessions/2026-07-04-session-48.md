## Del 1 — Syfte och scope

### Syfte och scope

Fortsättning på Pocock-integrationen (S47: fork-sviten 1–7 + bredd-svepet
KLARA, konkordans-täckningen stängd). Session 48 tar den största routade
mottagaren i Del 16-kartan: T57 — valet av git-nativt issues-substrat som
PRD-kort/skivor/do-work-kedjan ska bo i (ADR-068 p.7: specar som
issues-i-git, governade filer som substrat). Substratet är förkravet för
fork 4-bygget (PRD-kort-mall, issue-mall, etiketter, adapterade
to-prd/to-issues) och för do-work — och därmed på kritiska vägen till
ADR-068:s drift-metrik (p.8).

Ordnad scope:

1. Research-pass (research-gated per PI: förstapartskällor) över
   kandidaterna Backlog.md / git-issues / git-bug + ev. ytterligare
   git-nativa kandidater researchen ytar. Utvärderingskriterier
   härleds ur fork 4:s sju kontraktspunkter (Del 12 beslut 4) +
   governing-kraven (filer-i-git, grind-barhet).
2. Grillning i Code via /grill-with-docs (prövotids-datapunkt 8):
   verktygsval låses med Marcus.
3. Minimal-test av valet mot spoke-repot — litet, reversibelt.
4. Om utrymme: fork 4-byggets start (mallar + etiketter + adapterade
   skills per Del 12); annars nästa session.
