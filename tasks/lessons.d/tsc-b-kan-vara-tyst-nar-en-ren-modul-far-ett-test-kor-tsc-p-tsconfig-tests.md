# `tsc -b --noEmit` kan vara tyst lokalt när en ren modul får ett nytt api-pure-test — CI:s typecheck fäller TS6142; kör `tsc -p tsconfig.tests.json --noEmit`

**En ren `.ts`-modul som `import type`:ar från en `.tsx`-fil är grön i app-projektet men fäller under `tsconfig.tests.json` (inget `jsx`) så fort ett test i `tests/` importerar modulen — och lokal `npm run typecheck` (`tsc -b --noEmit`) kan gå grön på inkrementell build-info medan CI:s körning i rent träd fäller.** Mätt 2026-09-08 (S124 resume 1, TASK-438, PR #2468 första pushen `fe93535c`): `inbetalnings-handelser.ts` importerade `TidslinjeIkon` ur `Tidslinje.tsx`; Lint+TypeCheck och Pure+Build röda på `TS6142: … but '--jsx' is not set`; `npx tsc -p tsconfig.tests.json --noEmit` reproducerade felet lokalt. Fix: typen flyttad till `registrations/tidslinje-ikon.ts`, `Tidslinje.tsx` återexporterar. Regel: en ren modul som ska prövas creds-fritt importerar bara ur `.ts`-filer; när ett nytt test tillkommer under `tests/` — kör tests-projektet ensamt en gång innan push.
