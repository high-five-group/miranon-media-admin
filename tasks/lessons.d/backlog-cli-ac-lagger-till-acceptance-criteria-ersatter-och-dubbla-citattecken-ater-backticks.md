# Backlog-CLI:t: `--ac` LÄGGER TILL, `--acceptance-criteria` ERSÄTTER — och CLI-text i dubbla citattecken låter skalet äta backtick-orden [UNIVERSAL]

**Två mätta fällor i samma verktyg: (1) `task edit --ac "…"` lägger till ett nytt kriterium även när avsikten är att skriva om ett befintligt — fem dubbletter fick tas bort med `--remove-ac` (S124 Del 4, TASK-436); `--acceptance-criteria` ersätter listan. (2) En `--append-notes "…"`-sträng i DUBBLA citattecken med backticks i texten körs av zsh som kommandosubstitution: varje ord som står mellan backticks byts mot tomt och skalet skriver "command not found" — noten skrevs med hål och fick skrivas om i sin helhet (S124 resume 1, TASK-438, commit `19bbbefd`).** Regel: skriv om kriterier med `--acceptance-criteria`; skicka all fritext till CLI:t via `"$(cat <<'EOF' … EOF)"` med ENKELCITERAD heredoc-markör, aldrig som en dubbelciterad literal. Universellt: gäller varje CLI som tar prosa som argument.
