# Design Docs

Detta paket innehåller två kompletterande dokument:

- `DESIGN-MANIFESTO.md` — den filosofiska grunden
- `DESIGN-OPERATING-SYSTEM.md` — den operativa arbetsmodellen

## Hur de förhåller sig till varandra

**Manifestet** beskriver vad vi tror på.
Det definierar designens syfte, de oreducerbara sanningarna, principerna och den standard vi vill leva upp till.

**Operating System** beskriver hur vi arbetar.
Det översätter manifestets idéer till konkreta steg, leverabler, beslutregler, kvalitetsgranskning och arbetsdisciplin.

## Enkel tumregel

- Läs **Manifestet** för riktning.
- Använd **Operating System** för genomförande.

Tillsammans bildar de ett system:

- Manifestet skyddar arbetet från att tappa själ.
- Operating System skyddar arbetet från att tappa skärpa.

---

*Manifestet ger riktning. Systemet ger disciplin. Kvalitet uppstår när båda styr samma arbete.*
