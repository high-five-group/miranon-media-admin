# Triageetiketter

Skillsen talar om fem kanoniska triageroller. Den här filen mappar rollerna till de verkliga etikettsträngar som används i repots issue-tracker.

| Etikett i mattpocock/skills | Etikett i vår tracker | Betydelse |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Underhållare behöver utvärdera ärendet |
| `needs-info` | `needs-info` | Väntar på mer information från rapportören |
| `ready-for-agent` | `ready-for-agent` | Fullt specificerat och redo för en AFK-agent |
| `ready-for-human` | `ready-for-human` | Kräver mänsklig implementation |
| `wontfix` | `wontfix` | Kommer inte åtgärdas |

När en skill nämner en roll, till exempel ”applicera AFK-redo-triageetiketten”, använd motsvarande etikettsträng från tabellen.

Redigera den högra etikettkolumnen så att den motsvarar den vokabulär som faktiskt används.
