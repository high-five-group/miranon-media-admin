# Refaktoreringskandidater

Leta efter följande efter en TDD-cykel:

- **Duplicering** → extrahera funktion eller klass.
- **Långa metoder** → dela upp i privata hjälpare (behåll testerna på det publika gränssnittet).
- **Grunda moduler** → slå ihop eller fördjupa.
- **Feature envy** → flytta logik till platsen där datan finns.
- **Primitive obsession** → inför värdeobjekt.
- **Befintlig kod** som den nya koden visar är problematisk.
