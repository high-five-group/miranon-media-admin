# Next Roadmap After Evaluation

## A. Om Vi Fortsätter Med Odoo Online

Nästa 1-2 veckor:

- Verifiera Database Manager, duplicate, backup, plan och apps.
- Kör gratis fake event POC.
- Exportera Odoo fields.

Nästa månad:

- Anonymiserad Airtable sampleimport.
- Website/Shopify jämförelse.
- Beslut om paid flow ska testas.

Bygg inte:

- Custom modules.
- Skarpa fakturor/betalningar.
- Massmail/SMS.

## B. Om Vi Går Odoo.sh/Custom Modules

Motiveras först av verifierat gap. Bygg liten modul för exakt gap, med tester och upgrade-plan. Risker: kostnad, drift, versionsuppgraderingar och custom debt.

## C. Om Custom Webapp Förblir Huvudspår

Fokusera custom webappen på Lottas dagliga adminflöden, säker writemodell, närvarohistorik och rapportering. Återanvänd Odoo-idéer: event templates, explicit attendance, external IDs, staging/neutralized testing och tydligare scorecards.
